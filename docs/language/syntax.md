# قواعد لغة العربية (AlArabiya)

النسخة 2 — Scope: **Phase 2** (دوال + مكتبة مدمجة + تحكّم في الحلقات). هياكل البيانات (قوائم/قواميس) في مرحلة جاية.

---

## 1. الترميز والملفات

- الترميز: **UTF-8**. امتداد الملف: **`.arb`** (الامتداد القديم `.masr` لسه مقروء للرجوعية).
- أحرف التعليق: `#` حتى نهاية السطر.
- الترتيب (Whitespace): مسافات، تبويب، ومسافة/سطر جديد. **السطر الجديد `NEWLINE` له معنى** (نهاية أمر) ما دام القوس مفتوح.
- **القوس المفتوحة تلغي معنى السطر الجديد**: `(` `)` و `[` `]` — لو العمق > 0 فإن `\n` تُعامَل كمسافة عادية.

---

## 2. القيم (Literals)

| النوع | المثال | ملاحظات |
|---|---|---|
| رقم | `42`، `3.14`، `١٢٣`، `٣٫١٤` | أرقام عربية (٠-٩) + إنجليزية، `٫` فاصلة عشرية، `٬` فاصلة آلاف تُتجاهل |
| نص | `"أهلا"`, `"سطر\tجديد"` | `\"` `\\` `\n` `\t` `\r` `\u{1F600}` |
| منطقي | `صح` / `غلط` | |
| فراغ | `فراغ` | القيمة الفارغة (null) — تُطبع كـ `فراغ`، وقيمتها المنطقية "غلط" |
| دالة | — | الدوال قيم من الدرجة الأولى (تتخزّن وتترجّع وتتمرّر) |

---

## 3. التعبيرات وأولوياتها (من الأقل للأعلى)

| # | عوامل | الملاحظات |
|---|---|---|
| 1 | `أو` | يقيّم الشمال؛ لو `صح` يرجع `صح` من غير ما يقيّم اليمين |
| 2 | `و` | يقيّم الشمال؛ لو `غلط` يرجع `غلط` من غير ما يقيّم اليمين |
| 3 | `يساوي` `مش يساوي` | مقارنة تساوي |
| 4 | `أكبر من` `أصغر من` `أكبر أو يساوي` `أصغر أو يساوي` | مقارنة (كلمات) — ومكافئاتها `>` `<` `>=` `<=` |
| 5 | `زائد` `+` · `ناقص` `-` | جمع/طرح |
| 6 | `في` `*` · `على` `/` | ضرب/قسمة |
| 7 | `-` سالب (يظهر في بداية التعبير) | unary minus |
| 8 | الأقواس `( )` · اللصق `+` بين نصين | primary |
| 9 | `.` (ترميز فقط في Phase 1) | جاهز لـ member access |

**القيم المنطقية**: `و`/`أو` ترجّع قيمة، مش بالضرورة `صح`/`غلط` — نفس سلوك Python.

## 4. الأوامر (Statements)

### الطباعة
```
اطبع التعبير
```

### المتغيّر
```
خلي الاسم = التعبير
```
تعريف صريح **موجود أصلًا** (لو أول ظهور من غير `خلي` → تحذير `W3001` وينفّذ كالتعريف).

### إعادة إسناد
```
الاسم = التعبير
```

### الشرط
```
لو الشرط
    ...
غير كده
    ...
خلاص
```
`غير كده` اختياري. **`غير كده لو` (سلسلة else-if) خارج Phase 1** — استخدم `لو` منفصلة.

### التكرار بعدد
```
كرر عدد مرات
    ...
خلاص
```

### التكرار الشرطي
```
طالما الشرط
    ...
خلاص
```
**حد أقصى 1,000,000 دورة** ثم خطأ `E4003` (حماية من اللانهاية).

---

## 5. المتغيّرات

- الاسم: يبدأ بحرف حيوي أو `_`، ويتكوّن من حروف/أرقام/`_` و**علامات تشكيل عربية** (`ّ`، `ً` …).
- الحروف حساسة لحالة الأرقام بس (العربي مش حساس لحالة).
- Phase 1: **نطاق عام واحد** — التعريفات تفضل موجودة بعد نهاية الكتلة. `Environment(parent=)` جاهزة ومهيّأة لتفعيل الـ Scopes مع الدوال في Phase 2.

## 6. الأخطاء (Diagnostics)

| الرمز | المعنى |
|---|---|
| `E1001` | حرف غير متوقع (Lexer) |
| `E1002` | نص غير مُغلَق |
| `E1003` | رقم غير صالح |
| `E1004` | escape غير صالح |
| `E1005` | معلّق غير مُغلَق |
| `E2001` | ناقص `=` في تعريف |
| `E2002` | رمز/كلمة غير متوقعة |
| `E2003` | ناقص `)` |
| `E2004` | نهاية الملف قبل اكتمال الأمر |
| `E2005` | متوقّع identifier |
| `E2006` | متوقّع `)` للفتح |
| `E4001` | خطأ نوع في التشغيل |
| `E4002` | متغيّر غير معرّف |
| `E4003` | تجاوز حد الحلقات |
| `W3001` | تعريف ضمني (Auto-declare) |

الـ Parser **يستبعد السطر/الكتلة بعد الخطأ** (panic mode) ويجمّع أكثَر من خطأ في تمريرة واحدة — `أو` و `و` بيعتدوا على التقاطع (operator precedence) للـ Pratt parser.

## 7. مثال مرجعي

```
# تعليق
خلي س = ١٠
خلي ص = 20
اطبع "المجموع: " + (س + ص)

لو س أكبر من 5 و ص أكبر من 10
    اطبع "أكبر"
غير كده
    اطبع "أصغر"
خلاص
```

## 8. الدوال (Functions)

```
دالة <الاسم> (<معامل>، <معامل>، ...)
    ... الجسم ...
    رجّع <تعبير>
خلاص
```

- التعريف بـ `دالة`، والجسم بيتقفل بـ `خلاص` زي باقي الكتل.
- المعاملات بتتفصل بفاصلة — عربية `،` أو إنجليزية `,`.
- `رجّع <تعبير>` بترجّع قيمة وتوقف الدالة. `رجّع` من غير تعبير (أو دالة
  خلصت من غير `رجّع`) بترجّع `فراغ`. تُقبل `رجع` من غير شدّة كمان.
- الاستدعاء: `الاسم(قيمة، قيمة)`. الاستدعاء ممكن يكون تعبيرًا (`اطبع ف(3)`)
  أو أمرًا لوحده (`ف(3)`).
- الدوال **closures**: بتفتكر النطاق اللي اتعرّفت فيه.

```
دالة اجمع (أ، ب)
    رجّع أ زائد ب
خلاص
اطبع اجمع(2، 3)     # 5
```

## 9. التحكّم في الحلقات

- `اكسر` — بتوقف أقرب حلقة (`طالما` / `كرر`).
- `كمل` — بتروح للّفة اللي بعدها.
- لازم يكونوا **جوّه حلقة**؛ برّه بترمي `E4009`.

## 10. المكتبة المدمجة (Builtins)

| الدالة | الوظيفة |
|---|---|
| `طول(x)` | طول نص/قائمة/قاموس |
| `نوع(x)` | اسم نوع القيمة |
| `رقم(x)` | تحويل لرقم |
| `نص(x)` | تحويل لنص |
| `منطقي(x)` | القيمة المنطقية (صح/غلط) |
| `مطلق(x)` | القيمة المطلقة |
| `قرّب(x)` | تقريب لأقرب عدد صحيح |
| `اقرأ([رسالة])` | قراءة سطر من المستخدم (نص) |

أكواد أخطاء التشغيل الجديدة: `E4006` عدد مدخلات غلط · `E4007` مش دالة ·
`E4008` `رجّع` برّه دالة · `E4009` `اكسر`/`كمل` برّه حلقة · `E4010` خطأ في دالة مدمجة.
