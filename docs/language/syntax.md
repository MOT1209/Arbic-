# قواعد لغة العربية (AlArabiya)

النسخة 1 — Scope: **Phase 1** (بدون دوال ولا هياكل بيانات).

---

## 1. الترميز والملفات

- الترميز: **UTF-8**. امتداد الملف: **`.arb`** (الامتداد القديم `.masr` لسه مقروء للرجوعية).
- أحرف التعليق: `#` حتى نهاية السطر.
- المسافات: مسافات، تبويب، وسطر جديد. **السطر الجديد `NEWLINE` له معنى دايمًا** (نهاية أمر) — التعبير لازم يخلص في نفس السطر.
- **الأقواس مش بتلغي السطر الجديد**: `اطبع (1 +` ثم `2)` في السطر اللي بعده بيدي خطأ `E2002`. الرموز `[ ]` و `{ }` و `,` و `:` و `.` بتتقرأ كـ tokens، لكن مفيش قواعد نحوية بتستخدمهم في النسخة الحالية.

---

## 2. القيم (Literals)

| النوع | المثال | ملاحظات |
|---|---|---|
| رقم | `42`، `3.14`، `١٢٣`، `٣٫١٤` | أرقام عربية (٠-٩) + إنجليزية، `٫` فاصلة عشرية، `٬` فاصلة آلاف تُتجاهل |
| نص | `"أهلا"`, `"سطر\tجديد"` | `\"` `\\` `\n` `\t` `\r` `\u{1F600}` |
| منطقي | `صح` / `غلط` | |

**`شي` (None) غير مدعوم**: `خلي س = شي` بيدي `E4001` (متغيّر غير معرّف)، لأن `شي` مجرد اسم متغيّر عادي.

---

## 3. التعبيرات وأولوياتها (من الأقل للأعلى)

| # | عوامل | الملاحظات |
|---|---|---|
| 1 | `أو` | يقيّم الشمال؛ لو `صح` يرجع `صح` من غير ما يقيّم اليمين |
| 2 | `و` | يقيّم الشمال؛ لو `غلط` يرجع `غلط` من غير ما يقيّم اليمين |
| 3 | `يساوي` `مش يساوي` | مقارنة تساوي |
| 4 | `أكبر من` `أصغر من` `أكبر أو يساوي` `أصغر أو يساوي` | مقارنة (كلمات) — ومكافئاتها `>` `<` `>=` `<=` |
| 5 | `زائد` `+` · `ناقص` `-` | جمع/طرح |
| 6 | `في` `*` · `على` `/` | ضرب/قسمة |
| 7 | `-` سالب (يظهر في بداية التعبير) | unary minus |
| 8 | الأقواس `( )` | أقوى أولوية — بتجمّع اللي جوّاها |
| 9 | `.` | ترميز فقط — مفيش member access لسه |

**القيم المنطقية**: `و`/`أو` **بيرجّعوا `صح` أو `غلط` دايمًا** (مش قيمة أحد الطرفين زي Python)، وبيكمّلوا من غير ما يقيّموا الطرف التاني لو الشمال كفاية (short-circuit).

## 4. الأوامر (Statements)

### الطباعة
```
اطبع التعبير
```

### المتغيّر
```
خلي الاسم = التعبير
```
تعريف صريح **موجود أصلًا** (لو أول ظهور من غير `خلي` → تحذير `W3001` وينفّذ كالتعريف).

### إعادة إسناد
```
الاسم = التعبير
```

### الشرط
```
لو الشرط
    ...
غير كده
    ...
خلاص
```
`غير كده` اختياري. **`غير كده لو` (سلسلة else-if) خارج Phase 1** — استخدم `لو` منفصلة.

### التكرار بعدد
```
كرر عدد مرات
    ...
خلاص
```
عدد التكرار لازم يكون رقم. **السلوك الحالي**: العشري بيتقصّ لصحيح (`كرر 2.9 مرات` بتشتغل مرتين) والسالب بيتجاهل بصمت (`كرر -2 مرات` بتشتغل صفر مرات) — ده عيب معروف ومتسجّل في `docs/technical-debt.md`. لو العدد مش رقم أصلًا → `E4004`.

### التكرار الشرطي
```
طالما الشرط
    ...
خلاص
```
**حد أقصى 1,000,000 دورة** ثم خطأ `E4005` (حماية من اللانهاية).

---

## 5. المتغيّرات

- الاسم: يبدأ بحرف حيوي أو `_`، ويتكوّن من حروف/أرقام/`_` و**علامات تشكيل عربية** (`ّ`، `ً` …).
- المعرّفات حساسة لحالة الحروف اللاتينية (`x` ≠ `X`)؛ الحروف العربية ملهاش حالة أصلًا.
- Phase 1: **نطاق عام واحد** — التعريفات تفضل موجودة بعد نهاية الكتلة. `Environment(parent=)` جاهزة ومهيّأة لتفعيل الـ Scopes مع الدوال في Phase 2.

## 6. الأخطاء (Diagnostics)

| الرمز | المعنى |
|---|---|
| `E1001` | حرف غير متوقع في المصدر |
| `E1002` | نص غير مُقفَل |
| `E1003` | escape غير صالح |
| `E1004` | رقم غير صالح (زي `1.2.3`) |
| `E1005` | عامل غير متوقع |
| `E2001` | متوقّع token معيّن (زي `=`) |
| `E2002` | token غير متوقع |
| `E2003` | نهاية الملف قبل ما الأمر يكتمل |
| `E2004` | ناقصة `خلاص` لقفل الكتلة |
| `E2005` | متوقّع اسم متغيّر (identifier) |
| `E2006` | متوقّع نهاية سطر |
| `W3001` | إسناد لمتغيّر مش معلن (بيتعمل ضمنيًا) |
| `E4001` | متغيّر غير معرّف |
| `E4002` | قسمة على صفر |
| `E4003` | خطأ نوع في التشغيل |
| `E4004` | عدد تكرار مش رقم |
| `E4005` | تجاوز حد الحلقات (مليون دورة) |

بعد خطأ في أمر، الـ Parser بيتخطّى لحد نهاية السطر ويكمّل (panic mode)، عشان `arabic check` يجمع أكتر من خطأ في تمريرة واحدة. الـ expressions بتتحل بـ precedence climbing.

## 7. مثال مرجعي

```
# تعليق
خلي س = ١٠
خلي ص = 20
اطبع "المجموع: " + (س + ص)

لو س أكبر من 5 و ص أكبر من 10
    اطبع "أكبر"
غير كده
    اطبع "أصغر"
خلاص
```
