# قواعد لغة العربية (AlArabiya)

النسخة 11 — Scope: دوال + مكتبة مدمجة + تحكّم في الحلقات + قوائم/قواميس + حلقة `لكل` + وحدات/استيراد + معالجة الأخطاء + فحص أنواع ثابت اختياري (تدريجي) + أصناف ووراثة مفردة وتغليف وواجهات + دوال مجهولة (lambda) + دوال مزخرَفة ومولّدات + **context managers ومطابقة أنماط**.

---

## 1. الترميز والملفات

- الترميز: **UTF-8**. امتداد الملف: **`.arb`** (الامتداد القديم `.masr` لسه مقروء للرجوعية).
- أحرف التعليق: `#` حتى نهاية السطر.
- المسافات: مسافات، تبويب، وسطر جديد. **السطر الجديد `NEWLINE` بينهي الأمر** — التعبير لازم يخلص في نفس السطر، ما عدا جوه الأقواس المربعة `[ ]` أو المعقوفة `{ }` (القوائم/القواميس ممكن تمتد على أكتر من سطر).
- **الأقواس العادية `( )` مش بتلغي السطر الجديد**: `اطبع (1 +` ثم `2)` في السطر اللي بعده بيدي خطأ `E2002`.

## 2. القيم (Literals)

| النوع | المثال | ملاحظات |
|---|---|---|
| رقم | `42`، `3.14`، `١٢٣`، `٣٫١٤` | أرقام عربية (٠-٩) + إنجليزية، `٫` فاصلة عشرية، `٬` فاصلة آلاف تُتجاهل |
| نص | `"أهلا"`, `"سطر\tجديد"` | `\"` `\\` `\n` `\t` `\r` `\u{1F600}` |
| منطقي | `صح` / `غلط` | |
| فراغ | `فراغ` | القيمة الفارغة (null) — تُطبع كـ `فراغ`، وقيمتها المنطقية "غلط" |
| دالة | — | الدوال قيم من الدرجة الأولى (تتخزّن وتترجّع وتتمرّر) |

## 3. التعبيرات وأولوياتها (من الأقل للأعلى)

| # | عوامل | الملاحظات |
|---|---|---|
| 1 | `أو` | يقيّم الشمال؛ لو `صح` يرجع `صح` من غير ما يقيّم اليمين |
| 2 | `و` | يقيّم الشمال؛ لو `غلط` يرجع `غلط` من غير ما يقيّم اليمين |
| 3 | `يساوي` `مش يساوي` | مقارنة تساوي |
| 4 | `أكبر من` `أصغر من` `أكبر أو يساوي` `أصغر أو يساوي` | مقارنة (كلمات) — ومكافئاتها `>` `<` `>=` `<=` |
| 5 | `زائد` `+` · `ناقص` `-` | جمع/طرح |
| 6 | `في` `*` · `على` `/` | ضرب/قسمة |
| 7 | `-` سالب (يظهر في بداية التعبير) | unary minus |
| 8 | الأقواس `( )` · اللصق `+` بين نصين | أقوى أولوية |
| 9 | `.` | الوصول لأعضاء الكائن: `ك.اسم` أو `ك.طريقة()`, وطريقة ساكنة `صنف.طريقة()` |

**القيم المنطقية**: `و`/`أو` **بيرجّعوا `صح` أو `غلط` دايمًا** (مش قيمة أحد الطرفين زي Python)، وبيكمّلوا من غير ما يقيّموا الطرف التاني لو الشمال كفاية (short-circuit).

## 4. الأوامر (Statements)

### الطباعة
```
اطبع التعبير
```

### المتغيّر
```
خلي الاسم = التعبير
```
تعريف صريح **موجود أصلًا** (لو أول ظهور من غير `خلي` → تحذير `W3001` وينفّذ كالتعريف).

### إعادة إسناد
```
الاسم = التعبير
```

### الشرط
```
لو الشرط
    ...
غير كده
    ...
خلاص
```
`غير كده` اختياري. **`غير كده لو` (سلسلة else-if) خارج Phase 1** — استخدم `لو` منفصلة.

### التكرار بعدد
```
كرر عدد مرات
    ...
خلاص
```
عدد التكرار لازم يكون **عدد صحيح غير سالب**. القيم العشرية اللي ليها جزء كسري (`كرر 2.9 مرات`) والأعداد السالبة (`كرر -2 مرات`) وغير الأرقام (`كرر "خمسة" مرات`) كلها بتدّي `E4004` قبل ما الحلقة تبدأ. القيم زي `3.0` مقبولة لأنها عدد صحيح، و`كرر 0 مرات` مسموح وبينفّذ صفر لفات.

### التكرار الشرطي
```
طالما الشرط
    ...
خلاص
```
**حد أقصى 1,000,000 دورة** ثم خطأ `E4005` (حماية من اللانهاية).

## 5. المتغيّرات

- الاسم: يبدأ بحرف حيوي أو `_`، ويتكوّن من حروف/أرقام/`_` و**علامات تشكيل عربية** (`ّ`، `ً` …).
- المعرّفات حساسة لحالة الحروف اللاتينية (`x` ≠ `X`)؛ الحروف العربية ملهاش حالة أصلًا.

## 8. الدوال (Functions)

```
دالة <الاسم> (<معامل>، <معامل>، ...)
    ... الجسم ...
    رجّع <تعبير>
خلاص
```

- التعريف بـ `دالة`، والجسم بيتقفل بـ `خلاص` زي باقي الكتل.
- المعاملات بتتفصل بفاصلة — عربية `،` أو إنجليزية `,`.
- `رجّع <تعبير>` بترجّع قيمة وتوقف الدالة. `رجّع` من غير تعبير (أو دالة
  خلصت من غير `رجّع`) بترجّع `فراغ`. تُقبل `رجع` من غير شدّة كمان.
- الاستدعاء: `الاسم(قيمة، قيمة)`. الاستدعاء ممكن يكون تعبيرًا (`اطبع ف(3)`)
  أو أمرًا لوحده (`ف(3)`).
- الدوال **closures**: بتفتكر النطاق اللي اتعرّفت فيه.

```
دالة اجمع (أ، ب)
    رجّع أ زائد ب
خلاص
اطبع اجمع(2، 3)     # 5
```

- **الدوال المجهولة (lambda):** `دالة (<معاملات>)` في مكان التعبير، والجسم في
  السطر اللي بعده ويتقفل بـ `خلاص` — بنفس قواعد الجسم والإغلاق:

```
خلي مربع = دالة (س)
    رجّع س في س
خلاص
اطبع مربع(4)              # 16
اطبع طبّق(مربع، 6)        # بتمرير الدالة كقيمة
```

  الدالة المجهولة بتلتقط نطاق التعريف (closure)، ونوعها `دالة`، وبتتطبع
  `<دالة مجهولة>`. الجسم لازم يبدأ في سطر جديد؛ مفيش صيغة جسم في نفس السطر.

- **الدوال المزخرَفة (decorators):** سطر `مزخرف <تعبير>` قبل تعريف الدالة،
  وسطر لكل مزخرف. التطبيق من الأقرب للدالة للأبعد:

```
دالة سجل (دالة_أصلية)
    دالة ملفوفة (س)
        اطبع "قبل"
        خلي ناتج = دالة_أصلية(س)
        اطبع "بعد"
        رجّع ناتج
    خلاص
    رجّع ملفوفة
خلاص

مزخرف سجل
دالة ضعف (س)
    رجّع س في 2
خلاص
```

  المزخرف لازم يكون دالة بتاخد وسيط واحد (الدالة نفسها) وبترجّع قيمة
  تحلّ محلّ الاسم؛ مش مدعوم على الطرق ولا على `دالة` المجهولة.

- **المولّدات (generators):** أي دالة فيها `انتج <تعبير>` بترجّع مولّد
  كسول بدل ما تنفّذ جسمها كله فورًا:

```
دالة زوجية (ن)
    خلي ع = 0
    طالما ع أصغر من ن
        انتج ع
        ع = ع زائد 2
    خلاص
خلاص

لكل س في زوجية(6)
    اطبع س        # 0 2 4
خلاص
```

  المولّد بيتنفّذ خطوة بخطوة عند الطلب (`لكل`)، و`رجّع` بتنتهي به. الطباعة
  بتظهر `<مولّد>`، ومفيش `التالي()` ولا طرق صنف مولّدة.

- **Context managers (`استخدم`):** الكائن لازم صنف فيه `__دخول__` و`__خروج__`.
  ناتج `__دخول__` هو اللي بيتحط في المتغيّر، و`__خروج__` بتتنفّذ دايمًا
  (حتى مع `رجّع`/`اكسر`/خطأ) ومبتشفش الخطأ:

```
استخدم ملف("بيانات") باسم م
    اطبع م.مفتوح
خلاص
```

- **مطابقة الأنماط (`طابق`):** أول `حالة` تطابق بتتنفّذ، و`لو` شرط اختياري،
  و`غير كده` بديل. الأنماط: رقم أو نص أو `صح`/`غلط`/`فراغ`، أو اسم متغيّر
  (بيلتقط الموضوع)، أو `_` (أي حاجة من غير التقاط):

```
طابق قيمة
    حالة 1
        اطبع "واحد"
    حالة اسم
        اطبع اسم
    حالة _
        اطبع "تاني"
خلاص
```

  مفيش أنماط للقوائم/القواميس، ومفيش `اكسر`/`كمل` جوّه `طابق`.

## 9. التحكّم في الحلقات

- `اكسر` — بتوقف أقرب حلقة (`طالما` / `كرر`).
- `كمل` — بتروح للّفة اللي بعدها.
- لازم يكونوا **جوّه حلقة**؛ برّه بترمي `E4009`.

## 10. المكتبة المدمجة (Builtins)

| الدالة | الوظيفة |
|---|---|
| `طول(x)` | طول نص/قائمة/قاموس |
| `نوع(x)` | اسم نوع القيمة |
| `رقم(x)` | تحويل لرقم |
| `نص(x)` | تحويل لنص |
| `منطقي(x)` | القيمة المنطقية (صح/غلط) |
| `مطلق(x)` | القيمة المطلقة |
| `قرّب(x)` | تقريب لأقرب عدد صحيح |
| `اقرأ([رسالة])` | قراءة سطر من المستخدم (نص) |

أكواد أخطاء التشغيل الجديدة: `E4006` عدد مدخلات غلط · `E4007` مش دالة ·
`E4008` `رجّع` برّه دالة · `E4009` `اكسر`/`كمل` برّه حلقة · `E4010` خطأ في دالة مدمجة.

## 11. القوائم والقواميس

```
خلي ق = [1، 2، 3]          # قائمة
اطبع ق[0]                   # فهرسة (الفهرس السالب مدعوم: ق[-1])
ق[1] = 20                   # تعديل عنصر

خلي م = {"الاسم": "أحمد"، "السن": 25}   # قاموس
اطبع م["الاسم"]
م["ناجح"] = صح
```

- الفاصل بين العناصر فاصلة (`،` أو `,`)، والقوائم/القواميس ممكن تمتد على أكتر من سطر.
- مفاتيح القاموس لازم تكون نص/رقم/منطقي (مش قائمة أو قاموس) — وإلا `E4017`.
- أخطاء: `E4011` فهرس برّه الحدود · `E4012` مفتاح مش موجود · `E4013` فهرسة غلط.

## 12. حلقة `لكل` (for-each)

```
لكل <اسم> في <قائمة/نص/قاموس>
    ... الجسم ...
خلاص
```

بتمرّ على عناصر القائمة، أو حروف النص، أو مفاتيح القاموس. `اكسر`/`كمل`
شغّالين جوّاها. المرور على حاجة مش قابلة للتكرار بيدّي `E4014`.

## 13. الوحدات والاستيراد (Modules)

```
استورد "رياضيات"                 # بيجيب كل الأسماء المعرّفة في الملف
استورد "رياضيات" باسم ر          # كـ namespace: ر["جمع"](1، 2)
من "رياضيات" استورد جمع، ضرب      # أسماء مختارة بس
```

- الملف المستورد هو ملف `.arb` تاني (الامتداد اختياري في الاسم).
- المسار نسبي لمكان الملف المستورِد. الوحدة بتتنفّذ **مرّة واحدة** وتتخزّن.
- اسم الملف لازم يفضل جوّه مجلد المشروع: المسارات المطلقة واللي بتطلع بـ `..` بترفض بخطأ استيراد.
- أخطاء: `E4015` الملف مش موجود · `E4016` خطأ/استيراد دائري في الملف المستورد.

## 14. معالجة الأخطاء (Exceptions)

```
حاول
    ... كود ممكن يغلط ...
امسك <متغير>        # اختياري؛ المتغير اختياري كمان
    ... معالجة الخطأ ...
أخيرا               # اختياري
    ... بيشتغل دايمًا (نجاح أو فشل) ...
خلاص
```

- لازم يكون فيه `امسك` أو `أخيرا` على الأقل (وإلا `E2009`).
- `ارم <قيمة>` بترمي خطأ. ممكن ترمي أي قيمة (نص، قاموس، ...).
- في `امسك`، لو الخطأ جاي من التشغيل (زي القسمة على صفر) المتغير بيبقى
  **قاموس** فيه `"الرسالة"` و`"الكود"` و(لو موجود) `"اقتراح"`. لو الخطأ
  اترمى بـ `ارم` فالمتغير بياخد القيمة المرمية زي ما هي.
- `أخيرا` بتشتغل دايمًا — حتى مع `رجّع` أو `اكسر` أو `كمل` جوّه `حاول`.
- خطأ مش متمسك بيوقف البرنامج بكود `E4018`.

```
حاول
    اطبع 10 على 0
امسك خطأ
    اطبع خطأ["الرسالة"]     # مينفعش تقسم على صفر
خلاص
```

## 15. فحص الأنواع الثابت (اختياري / تدريجي)

ممكن تضيف **تعليقات أنواع** اختيارية بعد `:` — على المتغيرات، ومعاملات
الدوال، ونوع الإرجاع:

```
خلي العمر : رقم = 30
دالة اجمع (أ : رقم، ب : رقم) : رقم
    رجّع أ زائد ب
خلاص
```

- الأنواع المتاحة: `رقم`، `نص`، `منطقي`، `فراغ`، `قائمة`، `قاموس`، `دالة`، `أي`.
- **تدريجي (gradual)**: أي حاجة من غير تعليق نوعها `أي`، و`أي` متوافق مع كل
  الأنواع — فالبرامج القديمة تفضل سليمة.
- الفحص بيشتغل مع **`arabic check`** بس (مثل mypy مع python)؛ **`arabic run`
  بيتجاهل التعليقات** ويفضل ديناميكي بالكامل.
- بيكتشف: عدم تطابق النوع في التعريف/الإسناد/الإرجاع/مدخلات الدوال، عدد
  مدخلات غلط، واستخدام نوع غير معروف.
- الأكواد: `E5001` عدم تطابق نوع · `E5002` نوع غير معروف · `E5003` عدد مدخلات غلط.

```
خلي س : رقم = "نص"     # E5001: متوقّع رقم لكن لقيت نص
```

## 16. الأصناف (Classes)

```
صنف شخص
    دالة __تهيئة__(الاسم، السن)
        انا.الاسم = الاسم
        انا.السن = السن
    خلاص

    دالة عرّف_نفسك()
        رجّع "أنا " + انا.الاسم
```

```
    دالة __تهيئة__(الاسم، السن، المدرسة)
        الأساس.__تهيئة__(الاسم، السن)
        انا.المدرسة = المدرسة
    خلاص
خلاص
```

- `صنف <اسم> ... خلاص` بيعرّف صنفًا؛ جسمه طرق بس، وكل طريقة بتتعرف بـ `دالة`.
- `صنف <اسم> يرث <أب>` بيعرّف وراثة مفردة؛ الأب لازم يكون صنفًا معرّفًا
  قبله (`E4021` لو مش موجود أو مش صنف).
- `دالة ساكنة` بتعرّف طريقة ساكنة بتتنادى على الصنف نفسه: `شخص.نوع_الكائن()`.
- `__تهيئة__` اختيارية وبتتنادى لما تنادي الصنف: `شخص(...)`. بتستخدمها لتحط
  الخصائص. لو مش موجودة، نداء الصنف بياخد صفر مدخلات.
- جوّه الطرق غير الساكنة، `انا` اسم عادي بيشير للكائن الحالي.
- `.` للوصول للأعضاء: قراءة خاصية (`س.الاسم`)، كتابة خاصية (`س.السن = 31`)،
  أو نداء طريقة (`س.عرّف_نفسك()`).
- **الوراثة المفردة:** `صنف طالب يرث شخص` — الأب لازم يكون صنفًا معرّفًا
  قبله، وإلا `E4021`.
- الطرق (والطرق الساكنة) بتتورث، وإعادة تعريف طريقة بنفس الاسم في الابن
  بتحل محلّها. لو الابن معرّفش `__تهيئة__` بيستخدم تهيئة الأب تلقائيًا.
- لو الابن عرّف `__تهيئة__`، **مفيش نداء تلقائي** للأب؛ بينادي الأساس
  صراحةً: `الأساس.__تهيئة__(...)`.
- `الأساس` متاح جوّه طرق الكائن (مش الساكنة)، وبيتنسب للصنف اللي عرّف
  الطريقة. بيوصل لطرق الأب بس، مش لخصائصه.
- **الخصوصية:** `خاص` قبل الحقل أو الطريقة بتخلي العضو متاحًا جوّه نفس
  الصنف بس. الحقول الخاصة لازم تتعلن: `خاص الرصيد`، والوصول ليها من برّه
  أو من صنف ابن أو من `الأساس` بيدّي `E4022`.
- **الواجهات:** `واجهة` بتعلن توقيعات من غير جسم، والصنف بيلتزم بيها بـ
  `ينفذ`:

```
واجهة قابل_للطباعة
    دالة اطبع_نفسك() : نص
    دالة ساكنة اسم_النوع() : نص
خلاص

صنف شخص ينفذ قابل_للطباعة
    ...
خلاص
```

- الواجهة لازم تتعرف قبل الصنف (`E4024`)، والصنف لازم يوفّر كل توقيع
  بنفس الاسم والثبات وعدد المعاملات وأنواعها (`E4025`). الطريقة الموروثة
  العامة بتنفع، والخاصة لأ.
- **مفيش وراثة متعددة ولا وراثة واجهات** لحد دلوقتي.
- أخطاء: `E4019` عضو مش موجود · `E4020` وصول/إسناد عضو على قيمة مش كائن
  · `E4022` عضو خاص · `E4023` تعارض عضو خاص · `E4024` واجهة غير صالحة
  · `E4025` واجهة غير مكتملة.
- عند الطباعة: الكائن بيظهر `<كائن اسم>`، والصنف `<صنف اسم>`، و`نوع(كائن)`
  بترجّع `"كائن"`.
