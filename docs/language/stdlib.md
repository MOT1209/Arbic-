# المكتبة المدمجة (Standard Builtins)

دوال جاهزة متاحة في كل برنامج بدون استيراد. بتبلّغ عن الأخطاء بكود `E4010`
(مع موقع الاستدعاء)، وبتتأكد من عدد المدخلات (`E4006`).

## أساسية

| الدالة | المدخلات | الناتج |
|---|---|---|
| `طول(x)` | نص / قائمة / قاموس | عدد العناصر |
| `نوع(x)` | أي قيمة | اسم النوع (`رقم`، `نص`، `قائمة`، ...) |
| `رقم(x)` | نص / رقم / منطقي | تحويل لرقم |
| `نص(x)` | أي قيمة | تحويل لنص |
| `منطقي(x)` | أي قيمة | قيمتها المنطقية (صح/غلط) |
| `اقرأ([رسالة])` | رسالة اختيارية | سطر إدخال من المستخدم (نص) |

## رياضيات

| الدالة | الوظيفة |
|---|---|
| `مطلق(x)` | القيمة المطلقة |
| `قرّب(x)` | تقريب لأقرب عدد صحيح |
| `جذر(x)` | الجذر التربيعي (x ≥ 0) |
| `اس(أساس، قوة)` | الأساس مرفوع للقوة |

## قوائم

| الدالة | الوظيفة |
|---|---|
| `اضف(ق، قيمة)` | يضيف عنصرًا لآخر القائمة (يعدّلها) |
| `احذف(ق، فهرس)` | يشيل العنصر عند الفهرس ويرجّعه |
| `مدى(ن)` / `مدى(ا، ن)` | قائمة أرقام `[0..ن)` أو `[ا..ن)` |
| `مجموع(ق)` | مجموع أرقام القائمة |
| `اكبر(ق)` / `اصغر(ق)` | أكبر / أصغر رقم |
| `رتب(ق)` | قائمة جديدة مرتّبة (أرقام أو نصوص) |
| `اعكس(x)` | عكس قائمة أو نص |
| `يحتوي(حاوية، عنصر)` | هل العنصر موجود؟ (نص/قائمة/قاموس) |
| `مفاتيح(قاموس)` / `قيم(قاموس)` | قائمة المفاتيح / القيم |

## نصوص

| الدالة | الوظيفة |
|---|---|
| `قسّم(نص، فاصل)` | تقسيم النص لقائمة |
| `ادمج(قائمة، فاصل)` | دمج عناصر القائمة في نص |
| `استبدل(نص، قديم، جديد)` | استبدال كل تكرارات نص فرعي |

## وحدات قابلة للاستيراد

مجلد `al_arabiya/stdlib/` فيه وحدات مكتوبة بالعربية نفسها، بتتستورد بالاسم من أي
مشروع (وملف المشروع بنفس الاسم بياخد الأولوية):

| الوحدة | الدوال |
|---|---|
| `نصوص` | `مكرر(نص، عدد)` · `مقتبس(نص)` |
| `قوائم` | `مجموع(ق)` · `الأكبر(ق)` |
| `رياضيات` | `قوة(أساس، أس)` · `زوجي(عدد)` |

```arbic
استورد "نصوص"
اطبع مكرر("ها"، 3)      # هاهاها

استورد "قوائم"
اطبع مجموع([1، 2، 3])   # 6

استورد "رياضيات"
اطبع قوة(2، 10)        # 1024
```

الوحدات دي بتتنفّذ مرة واحدة وتصدّر كل أسماء المستوى الأعلى (زي أي ملف `.arb`).
