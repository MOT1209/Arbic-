# دليل الترحيل إلى 2.0

> **الوضع:** `0.1.0` هي النسخة الحالية، و«2.0» اسم الخارطة مش إصدارًا معلنًا
> (راجع [ADR-01](architecture/adr-01-name-and-versions.md)). المستند ده
> بيحصي **الكسر السلوكي المعروف** بين النسخة القديمة (`legacy/masry.py`)
> والنسخة الحالية، والخطوات اللي بتمنع مفاجآت.

## 1. مين محتاج يقرأ ده

- أي برنامج مكتوب لـ «مصري» القديم (`.masr`) أو لنسخة `0.1.0` الأولى.
- أي أداة خارجية بتستدعي `arabic` وبتعتمد على كود خروج أو مخرجات.

## 2. الكسر السلوكي المعروف

| # | قبل | بعد | الإصلاح |
|---|---|---|---|
| 1 | `كرر -2 مرات` بينفّذ صفر لفات بصمت | `E4004` | استخدم عددًا صحيحًا غير سالب |
| 2 | `كرر 2.9 مرات` بينفّذ لفتين | `E4004` | استخدم `2` أو `3` صريحًا |
| 3 | `استورد "../ملف"` بيقرأ أي مكان | `E4016` (ممنوع الخروج من المشروع) | انقل الملف جوّه المشروع أو ثبّته كحزمة |
| 4 | اسم حزمة أو اعتمادية فيه `..`/`/`/`:` بيتقبل | `PackageError` قبل أي نسخ/حذف | استخدم اسمًا بسيطًا |
| 5 | حزمة فيها symlink بتتنسخ | `PackageError` | احذف الـ symlinks أو ثبّت الحزمة من مصدر نظيف |
| 6 | حزمة ببصمات غلط بتتثبت | `PackageError` قبل أي حذف | أعد نشر الحزمة أو صحّح `البصمات` |

الكسر 1 و2 كان عيبًا مسجّلًا (TD-10)، و3–6 تحصين أمني. مفيش كسر تالت
معروف: النحوي والدلالات التانية متوافقة مع `legacy/masry.py` ومثبّتة
باختبارات الرجوعية (`tests/regression`).

## 3. خطوات الترحيل

1. **حدّث الأداة:**
   ```bash
   pip install -e .
   arabic version
   ```
2. **افحص المشروع:**
   ```bash
   arabic check ملف.arb        # نحوي + أنواع اختيارية
   arabic doctor .             # بيئة + حزمة.json + القفل + السجلّ
   ```
3. **شغّل اختباراتك** على المفسّر، وبعدها على الـ VM:
   ```bash
   arabic run ملف.arb
   arabic run --vm ملف.arb     # لو طبع تنبيه رجوع للمفسّر، ده متوقع
   ```
4. **راجع الاستيرادات:** أي `استورد` بيطلع بـ `..` لازم ينتقل جوّه المشروع
   أو يتحوّل لحزمة مثبتة في `حزم/`.
5. **راجع `حزمة.json`:** أسماء بسيطة، إصدارات `x.y.z`، وأضف `البصمات` لو
   الحزم بتتوزّع بين أكتر من جهاز.
6. **ثبّت من جديد** لو فيه حزم: `arabic packages install --registry <مسار>`.

## 4. اللي **مش** هيتغيّر (تعهّدات توافق)

- `.masr` هيفضل مقروء، وممنوع إضافة نحوي جديد ليه.
- أكواد الأخطاء القائمة مش هتغيّر معناها؛ الجديد بأرقام جديدة.
- أي Deprecation هيجي بتحذير `W3xxx` لمدة إصدار ثانوي واحد على الأقل.
- سلوك نطاق الكتل الحالي (بدون نطاق للكتل) مثبّت في
  [ADR-02](architecture/adr-02-block-scope.md) ولن يتغيّر في `0.x`.

## 5. لو الترقية كسرت برنامجك

1. شغّل `arabic check` — الكود والرسالة بيقولوا السبب.
2. راجع الجدول في §2؛ لو المشكلة مش موجودة فيه، ده **عيب** مش ترحيل.
3. بلّغ عنها في المستودع مع: البرنامج المصغّر، الأمر، والمخرجات الكاملة.
