# مواصفة لغة العربية (AlArabiya) — 0.1.0

> **الحالة:** مواصفة معيارية للسلوك **المنفّذ فعليًا** في هذا المستودع.
> كل بند هنا مبني على الكود واختبار ناجح؛ اللي مش منفّذ مذكور صراحةً في
> «حدود معروفة» ومش جزء من المواصفة.
>
> **الاسم والإصدار:** وفق [ADR-01](architecture/adr-01-name-and-versions.md).
> **جدول أكواد الأخطاء (مصدر الحقيقة):** [syntax.md §6](language/syntax.md).

## 1. اصطلاحات

- «لازم» = شرط إلزامي، «ممنوع» = خطأ برمجي، «ممكن» = سلوك مسموح.
- كل الأخطاء بتُبلَّغ كـ `Diagnostic` فيه كود + شدة + `Span` + اقتراح اختياري.
  الكود النهائي بيوقف التنفيذ، والتحذير (`W3xxx`) بيكمّل.

## 2. الملفات والترميز

- الترميز **UTF-8** (BOM مسموح ومُتجاهَل)، الامتداد **`.arb`**.
- `.masr` لسه مقروء للرجوعية، **وبدون أي نحوي جديد**.
- التعليق من `#` لآخر السطر.
- **حدود الأسطر:** السطر الجديد بينهي الأمر. التعبير لازم يخلص في نفس السطر،
  ما عدا جوّه `[ ]` و`{ }`؛ `( )` **مش** بتلغي السطر الجديد.

## 3. المعجم (Lexical)

### 3.1 المعرّفات

- بتبدأ بحرف أو `_`، وبعدها حروف/أرقام/`_` وعلامات تشكيل عربية
  (`\u064B`–`\u0652` وشدة `\u0651`).
- حسّاسة لحالة الحروف اللاتينية؛ العربية ملهاش حالة.

### 3.2 الأرقام

- أرقام إنجليزية `0-9`، عربية-هندية `٠-٩`، وفارسية `۰-۹`.
- `٫` فاصلة عشرية، `٬` فاصل آلاف بيتجاهَل.
- رقم بفاصلتين عشريتين (`1.2.3`) → `E1004`.

### 3.3 النصوص

- بين `"..."`، وبيانات الهروب: `\n` `\t` `\r` `\0` `\\` `\"` `\'`
  و`\u{XXXX}` (1–6 خانات hex).
- escape غير معروف → `E1003`، ونص غير مُقفل → `E1002`.
- النص **مش** متعدد الأسطر.

## 4. النحوي (Grammar)

```text
program     = { statement } EOF ;
statement   = "اطبع" expression NEWLINE
            | "خلي" IDENT [ ":" type ] "=" expression NEWLINE
            | assignOrExpr NEWLINE
            | "لو" expression NEWLINE { statement } [ "غير" "كده" NEWLINE { statement } ] "خلاص" NEWLINE
            | "كرر" expression "مرات" NEWLINE { statement } "خلاص" NEWLINE
            | "طالما" expression NEWLINE { statement } "خلاص" NEWLINE
            | "لكل" IDENT "في" expression NEWLINE { statement } "خلاص" NEWLINE
            | { "مزخرف" expression NEWLINE } "دالة" IDENT "(" [ params ] ")" [ ":" type ]
              NEWLINE { statement } "خلاص" NEWLINE
            | "استخدم" expression "باسم" IDENT NEWLINE { statement } "خلاص" NEWLINE
            | "طابق" expression NEWLINE { matchCase }
              [ "غير" "كده" NEWLINE { statement } ] "خلاص" NEWLINE
            | "صنف" IDENT [ "يرث" IDENT ] [ "ينفذ" IDENT { "," IDENT } ] NEWLINE
              { classMember } "خلاص" NEWLINE
            | "واجهة" IDENT NEWLINE { signature } "خلاص" NEWLINE
            | "رجّع" [ expression ] NEWLINE
            | "انتج" expression NEWLINE
            | ( "اكسر" | "كمل" ) NEWLINE
            | "استورد" STRING [ "باسم" IDENT ] NEWLINE
            | "من" STRING "استورد" IDENT { "," IDENT } NEWLINE
            | "حاول" NEWLINE { statement } [ "امسك" [ IDENT ] NEWLINE { statement } ]
              [ "أخيرا" NEWLINE { statement } ] "خلاص" NEWLINE
            | "ارم" expression NEWLINE ;

method      = "دالة" [ "ساكنة" ] IDENT "(" [ params ] ")" [ ":" type ]
              NEWLINE { statement } "خلاص" NEWLINE ;
classMember = [ "خاص" ] ( method | IDENT NEWLINE ) ;
signature   = "دالة" [ "ساكنة" ] IDENT "(" [ params ] ")" [ ":" type ] NEWLINE ;
matchCase   = "حالة" pattern [ "لو" expression ] NEWLINE { statement } ;
pattern     = NUMBER | STRING | "صح" | "غلط" | "فراغ" | IDENT | "_" ;
type        = typeAtom { "أو" typeAtom } ;
typeAtom    = ( IDENT | "فراغ" | "دالة" | "صنف" ) [ "[" type { "," type } "]" ] ;

assignOrExpr = expression [ "=" expression ] | IDENT "[" expression "]" "=" expression
             | expression "." IDENT "=" expression ;

expression  = orExpr ;
orExpr      = andExpr { "أو" andExpr } ;
andExpr     = equality { "و" equality } ;
equality    = comparison { ( "==" | "!=" | "يساوي" | "مش" "يساوي" ) comparison } ;
comparison  = additive { ( "<" | ">" | "<=" | ">=" | "أكبر" "من" | "أصغر" "من"
                        | "أكبر" "أو" "يساوي" | "أصغر" "أو" "يساوي" ) additive } ;
additive    = multiplicative { ( "+" | "زائد" | "-" | "ناقص" ) multiplicative } ;
multiplicative = unary { ( "*" | "في" | "/" | "على" | "%" ) unary } ;
unary       = ( "-" | "ناقص" ) unary | postfix ;
postfix     = primary { "[" expression "]" | "(" [ arguments ] ")" | "." IDENT } ;
primary     = NUMBER | STRING | "صح" | "غلط" | "فراغ" | IDENT
            | "[" [ expression { "," expression } ] "]"
            | "{" [ expression ":" expression { "," expression ":" expression } ] "}"
            | "(" expression ")"
            | "دالة" "(" [ params ] ")" [ ":" type ] NEWLINE { statement } "خلاص" ;
```

- الفواصل: `،` العربية و`,` الإنجليزية متكافئتان.
- `(` و`)` بتوسّع `span` التعبير الداخلي لتشمل القوسين (تشخيصات/LSP).
- `غير كده لو` مش مدعومة؛ استخدم `لو` منفصلة.

## 5. الدلالات (Semantics)

### 5.1 القيم

`رقم` (int/float)، `نص`، `منطقي`، `فراغ`، `قائمة`، `قاموس`، `دالة`، `صنف`
(وكائناتها).
`فراغ` بتتطبع `فراغ` وقيمتها المنطقية `غلط`.

### 5.2 الحقيقة (Truthiness)

القيم اللي بتتقيّم **غلط**: `غلط`، `0`، النص الفاضي، `فراغ`. غير كده **صح**.

### 5.3 الحساب

- `+ - * / %` (و`زائد ناقص في على`) على الأرقام؛ `/` بترجّع رقمًا عشريًا.
- `+` لو أحد الطرفين نص → لصق نصي (الطرف التاني بيتحوّل لنص).
- قسمة على صفر → `E4002`.
- `و`/`أو` **بيرجّعوا `صح`/`غلط` دايمًا** مع تقييم كسول (short-circuit).
- المقارنة على الأرقام مع بعض؛ الأعداد الصحيحة والعشرية متكافئة (`1 == 1.0`).

### 5.4 النطاق

- الكتل **مش** بتعمل نطاق؛ الدوال بس
  ([ADR-02](architecture/adr-02-block-scope.md)).
- أول إسناد لاسم غير معلن بيعرّفه مع تحذير `W3001`.
- `خلي` على اسم موجود بيعيد التعريف في نفس النطاق.

### 5.5 الحلقات

- `كرر N مرات`: `N` لازم يكون عددًا صحيحًا غير سالب؛ السالب أو العشري بجزء
  كسري أو غير الرقم → `E4004`. `3.0` مقبول، `0` بينفّذ صفر لفات.
- `طالما`: حد أقصى 1,000,000 دورة ثم `E4005`.
- `اكسر`/`كمل` برّه حلقة → `E4009`.

### 5.6 الدوال

- استدعاء بعدد مدخلات مختلف → `E4006`؛ استدعاء غير دالة → `E4007`.
- `رجّع` من غير قيمة، أو دالة خلصت، بترجّع `فراغ`.
- `رجّع` برّه دالة → `E4008`.
- closures بتلتقط نطاق التعريف بالمرجع.
- `دالة (<معاملات>) ... خلاص` دالة مجهولة (lambda) في مكان التعبير: نفس قواعد
  الجسم والإغلاق، والجسم لازم يبدأ في سطر جديد. نوعها `دالة` وبتتطبع
  `<دالة مجهولة>`.
- `مزخرف <تعبير>` قبل `دالة` بيطبّق المزخرفات من الأقرب للأبعد؛ المزخرف لازم
  يقبل وسيطًا واحدًا (الدالة) ويرجّع القيمة التي تحلّ محلّ الاسم.
- أي دالة فيها `انتج <تعبير>` بترجّع مولّدًا كسولًا يتنفّذ عند الطلب، وينتهي
  بـ `رجّع` أو بآخر جسمها. المولّد بيتطبع `<مولّد>` وبيُستهلك بـ `لكل`.
- `استخدم <تعبير> باسم <اسم>` بيستدعي `__دخول__` ويحط ناتجها في الاسم،
  و`__خروج__` بتتنفّذ دايمًا عند الخروج (نجاح/`رجّع`/`اكسر`/خطأ) ومبتشفش الخطأ.
- `طابق` بيقيّم الموضوع مرة واحدة وبيقارن بأنماط حرفية أو اسم التقاط أو `_`؛
  أول حالة تطابق (مع شرط `لو` إن وُجد) هي اللي بتتنفّذ، ولو مفيش تطابق
  ومفيش `غير كده` مفيش حاجة بتتنفّذ.

### 5.7 القوائم والقواميس

- فهرسة سالبة مدعومة (`ق[-1]`).
- فهرس برّه الحدود → `E4011`، مفتاح مش موجود → `E4012`، نوع فهرس غلط → `E4013`.
- مفاتيح القاموس: نص/رقم/منطقي فقط، وإلا `E4017`.

### 5.8 الأصناف

- `صنف <اسم> ... خلاص` بيعرّف صنفًا جسمه طرق (`دالة`) وطرق ساكنة
  (`دالة ساكنة`) وحقول خاصة معلنة (`خاص <اسم>`).
- `صنف <اسم> يرث <أب>` وراثة **مفردة**: الأب لازم يكون صنفًا معرّفًا قبل
  الابن (`E4021`)، ومفيش وراثة متعددة.
- `ينفذ <واجهة> [، <واجهة>]` بيلزم الصنف بتوقيعات الواجهات المعرّفة قبله
  (`E4024` لو مش واجهة، و`E4025` لو توقيع ناقص/مختلف).
- الطرق والطرق الساكنة بتتورث؛ إعادة تعريف نفس الاسم في الابن بتحل محلّ
  الأب. `الأساس.طريقة(...)` بينادي الأب على نفس `انا`، و`الأساس` بيتنسب
  لصنف الطريقة المُعرِّف ومتاح في طرق الكائن بس.
- `خاص` قبل الحقل أو الطريقة بيمنع الوصول من برّه الصنف (**E4022**)، بما
  في ذلك الأبناء و`الأساس`. إعادة استخدام اسم عضو خاص موروث → `E4023`،
  و`__تهيئة__` ممنوع تكون خاصة (`E4023`).
- `واجهة <اسم> ... خلاص` بتعلن توقيعات من غير جسم. الطريقة الموروثة العامة
  بتنفع في تنفيذ العقد، والخاصة لأ. مفيش وراثة واجهات ولا default methods.
- `__تهيئة__` اختيارية: لو موجودة بتتنادى عند نداء الصنف `اسم(...)`، ولو
  مش موجودة في الابن بيستخدم تهيئة الأب، وإلا فالنداء بياخد صفر مدخلات
  وإلا `E4006`. لو الابن عرّف تهيئة، مفيش نداء تلقائي للأب.
- جوّه الطرق غير الساكنة `انا` بيشير للكائن الحالي؛ الطرق الساكنة مفيهاش `انا`.
- `.` للوصول للأعضاء: خاصية أو طريقة على كائن، أو طريقة ساكنة على صنف.
  عضو مش موجود → `E4019`؛ وصول على قيمة مش كائن → `E4020`.
- الكائنات مرجعية: تمريرها لسرعة أو دالة بيعدّل نفس الكائن. الطباعة:
  الكائن `<كائن اسم>` والصنف `<صنف اسم>`، و`نوع(كائن)` = `"كائن"`.

## 6. الوحدات

- `استورد "اسم"` / `باسم ر` / `من "اسم" استورد أ، ب`.
- الاسم نسبي لمكان الملف المستورِد، والامتداد اختياري.
- **الاسم ممنوع يخرج من مجلد المشروع**: المسارات المطلقة أو اللي فيها `..`
  طالعة برّه → `E4016`.
- البحث: ملف شقيق، وإلا `حزم/<اسم>/` (أو `حزم/<اسم>/رئيسي.arb`) بالصعود
  من مجلد المستورِد.
- التنفيذ مرّة واحدة والتخزين مؤقت بالمسار المطلق.
- دورة استيراد → `E4016`، ملف مفقود → `E4015`، اسم مش موجود في
  `من ... استورد` → `E4016`.
- `باسم` بياخد **قاموس** بالأسماء المصدّرة، والوصول بـ `ر["اسم"]`.
  النقطة (`.`) للكائنات بس، مش لقاموس الوحدة.

## 7. معالجة الأخطاء

- `حاول` لازم يكون فيه `امسك` أو `أخيرا` (`E2009`).
- خطأ تشغيلي في `امسك` بيوصل كقاموس فيه `"الرسالة"` و`"الكود"` وربما
  `"اقتراح"`. خطأ `ارم` بيوصل بالقيمة المرمية كما هي.
- `أخيرا` بتشتغل دايمًا، حتى مع `رجّع`/`اكسر`/`كمل`.
- خطأ غير متمسك → `E4018` وكود خروج `1`.

## 8. الأنواع والفحص الثابت

- تعليقات `: نوع` على المتغيّرات والمعاملات ونوع الإرجاع.
- الأنواع: `رقم` `نص` `منطقي` `فراغ` `قائمة[T]` `قاموس[K، V]` `اختياري[T]`
  `دالة` `صنف` `أي`، والاتحاد `أ أو ب` (`اختياري[T]` سكر لـ`T أو فراغ`).
- تدريجي: بدون تعليق = `أي` ومتوافق مع الكل. القوائم والقواميس invariant،
  والاستدلال المحلي بيعطي `[1، "نص"]` النوع `قائمة[رقم أو نص]`.
- الفحص **في `arabic check` و`arabic build` بس**؛ `arabic run` بيتجاهل
  التعليقات ويفضل ديناميكيًا (ADR-05).
- **جدول رموز** لكل نطاق (الوحدات والدوال) + **تحليل واعٍ بالوحدات**: كل وحدة
  مستوردة بتتفحص مرة واحدة وأسماؤها المصدَّرة بتاخد أنواعها، وبنفس قواعد
  المسارات الأمنية بتاعة وقت التشغيل.
- **الوضع الصارم** `arabic check --strict`: تعليق نوع إلزامي على كل متغيّر
  ومعامل وإرجاع، وكل اسم لازم يكون معرّف (الـ lambda مستثناة من التعليقات).
- الأكواد: `E5001`–`E5008` (عدم تطابق، نوع غير معروف، عدد مدخلات، تعليق ناقص،
  أنواع فرعية غلط، اسم مستورد غير موجود، وحدة غير قابلة للتحليل، اسم غير معرّف).

## 9. الحزم

- `حزمة.json`: `الاسم` (إلزامي)، `الإصدار` (`x.y.z`)، `الاعتماديات`
  (اسم → قيد)، و`البصمات` الاختيارية (مسار نسبي → sha256 hex).
- الأسماء: ممنوع تكون فاضية أو `.`/`..` أو تحتوي `/ \ :` أو محارف تحكّم.
- القيود: `*`/`أي`، `^x.y.z`، أو إصدار بالظبط.
- `install` بيفحص كل الحزم (symlinks ممنوعة، البصمات لازم تطابق) **قبل** أي
  حذف/نسخ، وبعدها بيكتب `حزمة-قفل.json`.
- مفيش شبكة ولا سجلّ عام ولا سكربتات تثبيت.

## 10. التنفيذ

- المفسّر الشجري هو المرجع والافتراضي.
- VM بايت-كود اختياري (`arabic run --vm`)؛ لو البرنامج فيه حالة غير مدعومة
  بيرجع للمفسّر مع رسالة، فالمخرجات واحدة.
- أكواد الخروج: `0` نجاح · `1` خطأ لغوي (ترجمة/تشغيل) · `2` خطأ استخدام/ملف.

## 11. حدود معروفة (خارج المواصفة)

مفيش: وراثة متعددة، وراثة واجهات/default methods،
`ثابت`، sets/tuples، شرائح، interpolation، async/await،
playground، سجلّ حزم على الإنترنت، Python interop، IR،
optimizer. والمنسّق (`arabic format`) بيوحّد المسافات بس، وعزل التنفيذ
(`--sandbox`) بيشغّل عاملًا منفصلًا بحدود وقت/ذاكرة/مخرجات، وعلى Linux x86_64
بيحجب الشبكة وكتابة الملفات بـ seccomp؛ Windows/macOS لسه بدون حجب OS
([sandbox-design.md](architecture/sandbox-design.md)).

## 12. المطابقة (Conformance)

أي تنفيذ بديل للغة لازم:

1. يقبل نفس النحوي والنصوص أعلاه.
2. يرجّع نفس أكواد الأخطاء ونفس السلوك عند الفشل.
3. يحافظ على `W3001` والتحذيرات من غير ما يحوّلها لأخطاء.
4. يقرأ `.masr` بدون أي نحوي جديد.

الاختبارات الحالية هي المرجع التنفيذي للمواصفة: `tests/contracts` بيثبّت
كتالوج الأكواد وحدود أكواد الخروج.
