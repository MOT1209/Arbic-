# آلة البايت-كود (Bytecode VM)

خلفية تنفيذ تانية أسرع من المفسّر الشجري، بتشتغل على **نواة اللغة**. المفسّر
الشجري لسه هو **الافتراضي والمرجع**؛ الـ VM اختياري ومطابق له في النتائج
والأخطاء.

## الاستعمال

```bash
arabic run --vm مثال.arb     # شغّل عبر آلة البايت-كود
arabic bench مثال.arb        # قارن سرعة المفسّر بآلة البايت-كود
```

لو البرنامج بيستعمل ميزة برّه نواة الـ VM، `run --vm` بيرجع للمفسّر تلقائيًا
مع رسالة توضيحية — فالنتيجة دايمًا صحيحة.

## المسار

```
AST → مُصرِّف بايت-كود → Chunk (تعليمات + ثوابت) → آلة مكدّس (stack VM)
```

- `al_arabiya/vm/opcodes.py` — مجموعة التعليمات (`CONST`، `ADD`، `JUMP`، `CALL`، ...).
- `al_arabiya/vm/chunk.py` — `Chunk` (كود مسطّح + ثوابت + spans) و`VMFunction`.
- `al_arabiya/vm/compiler.py` — يحوّل الـ AST لبايت-كود، وبيحدّد الميزات غير المدعومة.
- `al_arabiya/vm/vm.py` — حلقة التنفيذ على المكدّس مع إطارات الاستدعاء (frames).

## المدعوم

متغيّرات (عامة ومحلية)، الحساب والمقارنات والمنطق (`و`/`أو` بتقييم كسول)،
`لو`/`غير كده`، `طالما`/`كرر`/`لكل` مع `اكسر`/`كمل`، الدوال والاستدعاء
والتكرار الذاتي، الدوال المدمجة، القيمة `فراغ`، القوائم والقواميس والفهرسة
(قراءة وكتابة)، معالجة الأخطاء `حاول/امسك/أخيرا/ارم`، الوحدات `استورد`
(بكل صيغها)، و**الدوال المتداخلة والإغلاقات الحقيقية (closures/upvalues)**.

**الإغلاقات:** المتغيّر المحلي اللي بتلتقطه دالة داخلية بيتحوّل لـ "خلية"
(Cell) مشتركة بالمرجع عبر سلسلة الـ closures، فالتعديل من جوّه أو برّه ظاهر
للطرفين — زي عداد بيفتكر حالته. تحليل الالتقاط بيتعمل قبل التصريف.

**الوحدات على الـ VM:** الاستيراد بيستخدم نفس مُحمّل المفسّر (نفس التخزين
المؤقت وكشف الاستيراد الدائري ورسائل الأخطاء). الوحدة نفسها بتتنفّذ على
المفسّر، والدوال المستورَدة بيتناديها الـ VM عبر جسر بيشغّلها على المفسّر —
فالنتيجة متطابقة.

## اللي لسه بيرجع للمفسّر

- فقط: `حاول` اللي فيه `رجّع`/`اكسر`/`كمل` بيقفز لبرّه ويعدّي على `أخيرا` (حالة نادرة).

في الحالة دي `run --vm` بيرجع للمفسّر تلقائيًا مع رسالة، فالنتيجة صحيحة دايمًا.

## الأداء

على برامج النواة (تكرار ذاتي/حلقات حسابية) التسريع عادة **بين ٢.5× و٤×**
مقارنةً بالمفسّر الشجري — لأن الـ VM بيتفادى إعادة توزيع الزيارة على الـ AST
واستخدام الاستثناءات للإرجاع. القياس الفعلي عبر `arabic bench`.

## حدود صادقة

نواة فقط (مش كل اللغة)، بايت-كود بأعداد صحيحة مسطّحة مع قفزات مطلقة، بلا
upvalues/closures حقيقية بعد. التوسّع لتغطية باقي اللغة مرحلة جاية.
