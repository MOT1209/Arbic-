# المصحّح (Debugger) — DAP

مصحّح العربية بيتكلّم **Debug Adapter Protocol** على stdio، فأي محرّر بيدعم DAP
(VS Code، Neovim، …) يقدر يوصله.

```bash
arabic debug مثال.arb        # خادم DAP على stdin/stdout
arabic debug --stdio         # من غير مسار: البرنامج بييجي في طلب launch
```

> stdout مخصّص لرسائل DAP بس. مخرجات البرنامج بتتبعت كأحداث `output`، والتشخيصات
> كـ `stderr` — عشان كده مفيش أي `print` عادي في وضع التصحيح.

## اللي مدعوم

| الطلب | السلوك |
|---|---|
| `initialize` | بيرد بالقدرات ويبعت حدث `initialized` |
| `launch` | بياخد `program` و`stopOnEntry` |
| `setBreakpoints` | نقاط توقف بأرقام سطور (1-based)، والرد `verified` |
| `configurationDone` | يبدأ تنفيذ البرنامج |
| `threads` | خيط واحد: «البرنامج» |
| `stackTrace` | المكدّس من الداخل للخارج بأسماء الدوال والسطور |
| `scopes` | «محلي» (نطاق الاستدعاء الحالي) و«عام» (الجذر) |
| `variables` | أسماء وقيم بصيغة الطباعة، مع نوع بايثون الداخلي |
| `continue` / `next` / `stepIn` / `stepOut` | استكمال / خطوة فوق / خطوة داخل / خروج من الدالة |
| `terminate` / `disconnect` | يقفل الجلسة (وقت التوقف) |

## إزاي بيشتغل

`al_arabiya/debugger/session.py` فيه `_DebugInterpreter` — تحت-كلاس من المفسّر
بيبلّغ الجلسة قبل **كل جملة** (مش تعبير)، وبيحتفظ بمكدّس إطارات فيه اسم الدالة
وسط السطر والبيئة. لما نقطة توقف تصيب، الجلسة بتوقف الحلقة وتقرأ رسائل DAP من
نفس الخيط، فمفيش سباقات ولا خيوط إضافية.

الخطوة على مستوى الجملة، وده مناسب للغة سطرية زي العربية:

- `next` بيوقف عند أول جملة على نفس عمق الاستدعاء أو أقل.
- `stepIn` بيوقف عند أي جملة، حتى جوّه دالة.
- `stepOut` بيوقف عند أول جملة بعد الرجوع من الدالة.

## VS Code

`editors/vscode/` فيه إضافة رفيعة (`package.json` + `extension.js`) بتسجّل
`DebugAdapterExecutable("arabic", ["debug", "--stdio"])`. استخدمها من المصدر
(Extension Development Host) لحد ما تتنشر على السوق؛ **مش متجرّبة على VS Code
نفسه هنا** — الجزء المختبَر هو الخادم نفسه.

`.vscode/launch.json`:

```json
{
  "type": "arabic",
  "request": "launch",
  "name": "تصحيح العربية",
  "program": "${workspaceFolder}/رئيسي.arb",
  "stopOnEntry": false
}
```

## حدود معروفة

- **المفسّر بس:** الـ VM مش متزوّد بنقاط تتبّع؛ `--vm` مش متاح مع `debug`.
- **نقاط توقف بسيطة:** مفيش شروط (`condition`) ولا `hitCondition` ولا `logMessage`.
- **المتغيرات مسطّحة:** القوائم والقواميس بتتعرض كنص، مش كأطفال قابلين للتوسيع.
- **`terminate` وقت التشغيل:** الرسائل بتتقرأ وقت التوقف بس؛ أثناء تنفيذ طويل
  لازم المهلة أو إغلاق الاتصال.
- **الوحدات المستوردة:** بتتنفّذ في مفسّرها الخاص من غير نقاط تتبّع (نفس حد
  `استورد` الحالي).
