# مدير الحزم (Package Manager)

مدير حزم **محلّي (offline)**: مفيش شبكة ولا سجلّ مركزي ولا نشر. السجلّ مجرّد
مجلد على جهازك، والتثبيت بيـ"يضمّن" (vendor) الحزم جوّه مشروعك في مجلد `حزم/`.

## ملف المشروع: `حزمة.json`

```json
{
  "الاسم": "تطبيقي",
  "الإصدار": "1.0.0",
  "الاعتماديات": { "مطبوعات": "^1.0.0" }
}
```

قيود الإصدار (SemVer مبسّط): `1.2.3` (بالظبط) · `^1.2.3` (نفس الـ major، أحدث
أو يساوي) · `*` أو `أي` (أي إصدار).

## السجلّ (Registry)

مجلد منظّم كده:

```
<السجلّ>/<اسم الحزمة>/<الإصدار>/...ملفات .arb...
                                └ حزمة.json (اختياري، لاعتماديات الحزمة نفسها)
```

## الأوامر

```bash
arabic packages install [مجلد] --registry <مسار السجلّ>
arabic packages list    [مجلد]
```

أو عبر المتغيّر `ARABIC_REGISTRY` بدل `--registry`. الأمر `حزمة` اسم عربي
مكافئ لـ `packages`.

`install` بيحلّ كل الاعتماديات (ومتعدّياتها)، يختار أعلى إصدار يطابق القيد،
يكتشف التعارضات والدوائر، ينسخ الحزم في `حزم/`، ويكتب ملف قفل `حزمة-قفل.json`.

## الاستيراد

بعد التثبيت، `استورد "اسم"` بيلاقي الحزمة في `حزم/` تلقائيًا (بيدوّر لأعلى
لأقرب مجلد `حزم/`، فحزمة ممكن تستورد اعتمادياتها). شغّال على المفسّر والـ VM
بنفس الطريقة.

```
استورد "مطبوعات"
عنوان("أهلا بالحزم")
```

## حدود صادقة

- **محلّي بس**: لا تنزيل من الإنترنت، لا سجلّ عام، لا نشر (`publish`).
- حلّ التعارض مبسّط (بياخد أعلى إصدار للجذر الأول، ويتأكد إنه يطابق باقي
  القيود، وإلا بيبلّغ تعارض) — مش محلّل SAT كامل.
- `حزم/` و`حزمة-قفل.json` ناتج تثبيت (مُهمَلين في git بشكل افتراضي).
