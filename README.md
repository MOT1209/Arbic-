# لغة مصري 🇪🇬

> لغة برمجة بسيطة كلماتها بالعامية المصرية — اتبنت من الصفر عشان نفهم إزاي أي لغة برمجة بتشتغل من جوه.

اكتب `اطبع "أهلا يا عالم"` وشغّلها فعلاً. 😎

```
اطبع "أهلا يا عالم"

خلي الاسم = "أحمد"
لو الاسم يساوي "أحمد"
    اطبع "أهلاً بيك يا " + الاسم
خلاص
```

---

## ✨ إيه اللي بتقدر تعمله

- **طباعة:** `اطبع`
- **متغيرات:** `خلي س = 5`
- **الشرط:** `لو ... غير كده ... خلاص`
- **التكرار بعدد:** `كرر 3 مرات ... خلاص`
- **التكرار الشرطي:** `طالما ... خلاص`
- **حساب** بالرموز (`+ - * /`) أو بالكلمات (`زائد ناقص في على`)
- **مقارنات** بالعربي: `أكبر من`، `أصغر من`، `يساوي`، `مش يساوي`
- **منطق:** `و`، `أو`
- بيقرا **الأرقام العربية** (٠-٩) والإنجليزية
- **رسائل الأخطاء نفسها بالمصري** ✅

---

## 📦 المتطلبات

- **Python 3.7** أو أحدث. اتأكد بإنك تكتب في الترمينال:

```bash
python --version
```

لو مش متسطّب، نزّله من [python.org](https://www.python.org/downloads/) — وفي ويندوز حطّ علامة صح على **"Add Python to PATH"** وإنت بتسطّب.

## 🚀 التشغيل

نزّل الريبو أو انسخه:

```bash
git clone https://github.com/ahmedfox1/masry.git
cd masry
```

### الطريقة ١ — تشغيل ملف

اكتب برنامجك في ملف بامتداد `.masr` (زي `مثال.masr`) وشغّله:

```bash
python masry.py مثال.masr
```

### الطريقة ٢ — الوضع المباشر (REPL)

شغّل من غير اسم ملف، واكتب أوامرك سطر بسطر:

```bash
python masry.py
```

```
مصري> اطبع "أهلا"
أهلا
مصري> خروج
```

## 📖 قاموس اللغة

| بالمصري | المعنى | مثال |
|---|---|---|
| `اطبع` | طباعة | `اطبع "أهلا"` |
| `خلي` | عمل متغير | `خلي س = 5` |
| `لو` / `غير كده` / `خلاص` | شرط | انظر تحت |
| `كرر ... مرات` | تكرار بعدد | `كرر 3 مرات` |
| `طالما` | تكرار شرطي | `طالما س أصغر من 10` |
| `أكبر من` / `أصغر من` | مقارنة | `س أكبر من 5` |
| `أكبر أو يساوي` / `أصغر أو يساوي` | مقارنة | `س أصغر أو يساوي 10` |
| `يساوي` / `مش يساوي` | مساواة | `س يساوي 5` |
| `و` / `أو` | منطق | `س أكبر من 1 و س أصغر من 9` |
| `زائد` `ناقص` `في` `على` | حساب | `5 زائد 3` |
| `صح` / `غلط` | قيم منطقية | `خلي شغال = صح` |
| `#` | تعليق | `# ده تعليق` |

## 🧪 مثال كامل

```
# أول برنامج بلغة مصري 🇪🇬
اطبع "أهلا يا عالم"

خلي السن = 25
لو السن أكبر من 18
    اطبع "إنت راجل كبير 💪"
غير كده
    اطبع "لسه صغير"
خلاص

كرر 3 مرات
    اطبع "بحبك يا مصر ❤️"
خلاص

خلي العداد = 1
طالما العداد أصغر أو يساوي 5
    اطبع "العدد: " + العداد
    خلي العداد = العداد + 1
خلاص
```

## 🧠 بتشتغل إزاي؟

المترجم بيعدّي بالكود على نفس الأربع مراحل اللي بتعملها أي لغة مُفسَّرة:

1. **Lexer** — بيقطّع النص لكلمات (Tokens)
2. **Parser** — بيفهم القواعد ويبني شجرة الأوامر
3. **AST** — شجرة بتمثّل البرنامج
4. **Interpreter** — بيمشي على الشجرة وينفّذ

## ⚠️ ملاحظة مهمة

**دي لغة تعليمية (toy language)، مش لغة إنتاج.**

الهدف منها إنك تفهم إزاي اللغات بتتبني من جوه — مش إنك تشتغل بيها مشاريع حقيقية. هي **مالهاش:** دوال، هياكل بيانات (لستات/قواميس)، مكتبات، تعامل مع ملفات أو نت، ولا مجتمع أو أدوات. وطبيعي إنها أبطأ من بايثون لأنها متبنية فوقيها.

باختصار: **ممتازة للتعلّم، مش للشغل** — وده مقصود.
