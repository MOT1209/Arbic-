# AlArabiya — العربية

> لغة برمجة تعليمية بتخاطبك بالعربي الفصيح والعامية — مُعاد بناؤها من مشروع "مصري" إلى مُترجم منظّم، معياري، وقابل للاختبار.

```bash
pip install -e .
arabic run examples/hello.arb
# أهلا بالعالم
```

---

## ✨ المميزات

- **كلمات مفتاحية عربية**: `اطبع`، `خلي`، `لو`، `كرر`، `طالما`، `خلاص`
- **حساب ومقارنة بالعربي**: `زائد ناقص في على`، `أكبر من`، `يساوي`، `مش يساوي`، `أكبر أو يساوي`
- **منطق قصير**: `و`، `أو` (بيقيّموا الشمال الأول، واليمين بس لو محتاجينه)
- **أرقام عربية (٠-٩) وإنجليزية**، وفاصلة عشرية `٫` وفاصلة آلاف `٬`
- **strings** ب逃脱ات كاملة `\n \t \" \\ \u{...}`
- **رسائل أخطاء مصرية** بأكواد مرجعية (`E1001`، `E2002`…) ونسب للكود الأصلي
- **UTF-8 من أول حرف لآخر** — الـ positions والـ spans محسوبة على الحروف العربية

## 🚀 التشغيل

```bash
git clone https://github.com/ahmedfox1/masry.git
cd masry
pip install -e .
```

| الأمر | الوظيفة |
|---|---|
| `arabic run مثال.arb` | تشغيل ملف (أو `arabic مثال.arb` اختصارًا) |
| `arabic check مثال.arb` | فحص بدون تشغيل — يطبع كل الأخطاء |
| `arabic` / `arabic repl` | وضع تفاعلي (REPL) — اكتب `خروج` للإنهاء |
| `arabic version` | رقم الإصدار |
| `arabic help` | المساعدة |

**رموز الخروج**: `0` نجاح · `1` خطأ لغوي (ترجمة/تشغيل) · `2` خطأ استخدام أو ملف

    اطبع "بحبك يا مصر ❤️"

خلاص

## 🧠 البنية

```
الكود → Lexer → Tokens → Parser → AST → Interpreter → المخرجات
              ↘ Diagnostics (أكواد أخطاء + مواقع) ↗
```

| الطبقة | المسؤولية |
|---|---|
| `compiler/positions` | `Position` / `Span` — مواقع دقيقة بالحروف |
| `compiler/diagnostics` | الأخطاء والتحذيرات + عرضها بشكل جميل |
| `compiler/lexer` | تقطيع Unicode بأمان + تتبّع الأخطاء مع استمرار |
| `compiler/parser` | **Pratt parser** (precedence climbing) + استرداد بعد الخطأ |
| `compiler/ast` | nodes بـ `dataclass` + visitor |
| `runtime/interpreter` | تنفيذ الشجرة + `Environment` (سلسلة Scopes جاهزة) |
| `cli` | أوامر `run`/`check`/`repl` + كشف الإدخال الناقص |
